Rasmee Thaana source bundle

1. Create a clean virtual environment with the tested Python (CPython 3.10.8) and install the pinned packages:

python3.10 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt

2. Release build: build_and_verify.sh is the ONLY release recipe. It pins the release epoch, version and
   hinting, checks the SHA-256 and installs only a matching font. Then run the release gate:

PYTHON=.venv/bin/python bash build_and_verify.sh && .venv/bin/python tools/baseline_check.py RasmeeThaana-Regular.ttf

   The two steps are chained with &&: the gate runs only on a freshly verified build, so an older
   RasmeeThaana-Regular.ttf can never mask a failed rebuild.

   For reference only, the BUILD-ONLY command it wraps is shown below. It does no digest check and is not a
   release build; do not ship its output without the chained command above:

env -i PATH="$PATH" HOME="$HOME" SOURCE_DATE_EPOCH=1795737600 FONT_VERSION=1.007 .venv/bin/python tools/build.py build-only.ttf

   Expected SHA-256 of RasmeeThaana-Regular.ttf: a2ae5dec5ff661f22ad44bf9bd1a3c7a49119983e6c979a676d5ba712102240a

3. QA. Faruma is NOT included; it belongs to the President's Office. Reviewers with authorised access
   save it as Faruma.ttf beside this file. The audited file has SHA-256
   ff5985587f10897623704d8269b83e9f63e49dd58625078cac81204ee4d797e5.
   baseline_check needs no Faruma. release_qa runs all four checks and 24 designated, self-verified
   controls. Every command exits with status 1 on any failure, invalid or missing input, or unknown option.
   release_qa interrupted with Ctrl-C writes a 'cancelled' SUMMARY.txt and exits with status 130.

.venv/bin/python tools/baseline_check.py RasmeeThaana-Regular.ttf
.venv/bin/python tools/clearance.py RasmeeThaana-Regular.ttf --ref Faruma.ttf
.venv/bin/python tools/shapecheck.py RasmeeThaana-Regular.ttf --ref Faruma.ttf --corpus spec/corpus.txt
.venv/bin/python tools/script_tests.py RasmeeThaana-Regular.ttf --ref Faruma.ttf
.venv/bin/python tools/clearance_full.py RasmeeThaana-Regular.ttf --ref Faruma.ttf
.venv/bin/python tools/detail_plates.py RasmeeThaana-Regular.ttf plates --ref Faruma.ttf
.venv/bin/python tools/release_qa.py RasmeeThaana-Regular.ttf --ref Faruma.ttf --out qa-logs
